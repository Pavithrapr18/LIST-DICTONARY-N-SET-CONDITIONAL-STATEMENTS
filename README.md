Python Assignment 2 – Data Structures

📌 Project Overview

This assignment focuses on understanding and implementing basic Python data structures and conditional statements. It covers Lists, Dictionaries, Sets, and IF-ELIF-ELSE statements through simple practical programs.

🎯 Objectives

- Understand list creation, modification, and accessing elements.
- Perform different list operations such as append, insert, remove, pop, extend, and sort.
- Create and manipulate dictionaries.
- Understand dictionary keys, values, and items.
- Learn set operations and understand how sets handle duplicate values.
- Apply conditional statements to categorize performance based on scores.

🛠️ Topics Covered

1. Lists

- List creation
- Append and insert elements
- Remove and pop elements
- Extend and sort lists
- Find maximum, minimum, and sum
- Access list elements using indexing and slicing
- Reverse a list

2. Dictionaries

- Dictionary creation
- Access student marks
- Add new student records
- Update existing marks
- Display keys, values, and key-value pairs

3. Sets

- Set creation
- Understanding duplicate removal
- Set mutability and indexing
- Union operation
- Intersection operation

4. Conditional Statements

- IF, ELIF, and ELSE
- User input and score validation
- Performance categorization:
  - Above Average
  - Average
  - Below Average
